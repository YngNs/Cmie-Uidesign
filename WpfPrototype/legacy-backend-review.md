# 三相电机旧 VB 后端迁移评审

评审对象：`三相电机-20220610/三相电机-20220610/Test`

## 1. 旧系统实际承担的后端职责

### 1.1 配置与启动

- 从 `试验信息.ini`、`数据存储配置.ini` 读取数据库、数据目录和通讯参数。
- 支持 Access 与 SQL Server 两种试验数据库，并另外维护一个共享数据库。
- 启动时连接数据库、检查数据表和字段，并尝试补齐缺失结构。
- 防止同一程序重复运行。

主要来源：`startApp.vb`、`ModGlobeVariable.vb`、`ModTableVerfy.vb`。

### 1.2 项目和试验记录 CRUD

每类试验使用独立数据表，已确认包括：

- 电阻测定数据表
- 空载试验数据表
- 负载特性试验数据表
- 负载特性分析 A 法数据表
- 负载特性分析数据表（B/C/E 法共用分类号区分）
- 圆图法效率计算数据表
- 堵转试验数据表
- TN 试验数据表
- 温升试验曲线表
- 最大转矩计算数据表
- 振动和噪声试验数据表
- 转动惯量试验数据表
- 变频电动机负载特性数据表
- 用户管理表和型号参数表

典型记录字段为：

- `ID`
- `项目编号`
- `分类号`
- `试验说明`
- `项目建立时间`
- `默认有效值`
- `试验数据`（二进制）

典型操作流程：按项目编号/分类号查询 → DataSet/DataTable 编辑 → 新增或覆盖 → `OleDbDataAdapter.Update`；同时支持选择记录、读取、删除、设置默认有效记录。

主要来源：`FrmR.vb`、`frmNoLoadTest.vb`、`frmSampleBE.vb`、`frmSampleC.vb`、`frmAnalysis*.vb`、`ClsDataBaseOP.vb`、`ClsDataSetOP.vb`。

### 1.3 工作表序列化

旧系统没有逐列保存所有试验表，而是把 FlexCell 单元格转换为带“字段名 + 索引”的 `DataTable`，调用 `WriteXml(..., WriteSchema)` 生成 XML 字节，再 Deflate 压缩后写入 `试验数据` 二进制字段。读取时执行相反流程。

这个设计的可取之处是字段具有业务名称，例如：

- `定子UV直流电阻初始值`
- `规定折算温度定子相电阻值`
- `定子绕组不平衡度`
- `检温计直流电阻` + 通道索引

主要来源：`FrmR.vb:337-470`、各试验窗体的 `CellToBin/BinToCell`、`ClassCompress.vb`。

### 1.4 计算与数据分析

- 电阻：Y/Δ 线电阻与相电阻换算、规定温度折算、不平衡度、冷热态电阻温升。
- 通用数学：多项式最小二乘、线性/对数拟合、插值、求导、曲线平移。
- 空载：空载电流/损耗曲线、机械损耗与铁耗分离。
- A/B/C/E/H 法：定转子铜耗、铁耗、风摩耗、杂散损耗、效率、功率因数、额定点拟合。
- TN、最大转矩、堵转、转动惯量、温升等专用算法。

主要来源：`ClassRDeal`（位于 `ClassFileFileOP.vb`）、`ClsPolyFitOP.vb`、`ClassModeA.vb`、`ModEffAnalysis.vb`、`ClassTNAnalysis.vb`、`modDataAnalysis.vb`。

### 1.5 设备通讯与实时采集

- Siemens PLC：`libnodave.dll`，支持 TCP/串口、DB 区字节读写。
- Modbus TCP/RTU：原生 Socket 与 `ModbusTCP.dll` 两套实现。
- WT3000/WT1800：SCPI/TMCTL，配置接线、量程、测量项、谐波与电机输入。
- MW100：TCP 温度通道采集。
- RDC2512B、8961C、XK3012：串口电阻/电量/转矩设备。
- Kistler 4700、QZ8962A1、XJP 等：Socket、串口或厂商 DLL。
- 定时轮询、状态机、量程和实时数据解析。

主要来源：`ClassPLC.vb`、`ClassModBus*.vb`、`ClassWT*.vb`、`ClassMW100.vb`、`ClassRDC2512B.vb`、`Class8961C.vb`、`ClassKistler4700.vb`、`frmCommulication.vb`。

### 1.6 文件、Excel、报表

- 原始工作表文件导入导出。
- Excel Interop 与 Aspose.Cells 读写、模板填充、工作簿合并。
- 图片、图表、打印预览和报表输出。
- 二进制文件、文本文件、Deflate 压缩与解压。

主要来源：`ClassAsposeCell.vb`、`ClassExcelOP.vb`、`ClassFileFileOP.vb`、`ClassCompress.vb`。

| 旧 VB 能力 | 当前 WPF 状态 | 迁移判断 |
|---|---|---|
| 项目资料保存 | 本地 JSON 已实现 | 已覆盖，可继续扩充字段 |
| 单条工作表保存/读取/删除 | 本地 JSON 已实现 | 已覆盖基础 CRUD |
| 字段名 + 索引序列化 | 原先只有 TextBox 顺序数组 | 已为电阻试验加入命名字段并兼容旧数组 |
| 多记录、试验说明、默认有效值 | 未实现 | 建议下一阶段增加记录列表与版本管理 |
| 电阻折算和不平衡度 | 原先只有通用均值统计 | 本次已迁移并接入“阻值计算” |
| 空载/A 法等专业算法 | UI 已有，算法未接 | 可迁移，但必须先准备旧系统输入输出测试样本 |
| 实时设备采集 | 当前为模拟数据 | 可迁移协议思想，不能直接复制旧 DLL 绑定 |
| Access/SQL Server | 当前 JSON | 暂不建议恢复；单机原型优先 SQLite 或 JSON |
| Excel/Aspose 报表 | 未接 | 可迁移工作流，不建议直接复用旧版商业 DLL |
| 用户权限与审计 | 仅 UI 演示 | 需要重新设计密码哈希、角色和审计日志 |

## 4. 暂不直接迁移的内容

### 4.1 设备类

旧类依赖 32 位 COM/OCX、厂商 DLL、P/Invoke 和阻塞式 Timer。直接复制到 .NET 8 x64 WPF 可能导致进程崩溃、线程卡死或数据字节序错误。需要先确认：

- 设备准确型号和固件版本；
- IP/串口参数、寄存器表、SCPI 指令集；
- DLL 位数和授权；
- 可连接的测试设备或协议模拟器。

建议重写为 `IDeviceDriver` 异步接口，并把 PLC、功率分析仪、温度采集和转矩仪分成独立驱动。

### 4.2 A/B/C/E/H、TN 和效率算法

这些算法可以转成 C#，但文件之间共享大量全局结构、拟合对象和标准分支。没有旧程序的同一组原始数据与期望结果时，无法证明迁移后数值一致。建议先导出 3–5 组匿名测试项目作为回归基准，再逐法迁移。

### 4.3 旧数据库自动建表

`ModTableVerfy.vb` 不是普通可读 VB 文本，文件头也不是标准 UTF 文本，当前无法审计其中的完整建表字段；`数据字典.xls` 在当前运行环境也无法通过规定的表格工具解析。因此暂不生成 Access/SQL Server 兼容层。

### 4.4 BinaryFormatter/SoapFormatter 与旧 Aspose DLL

这些技术在现代 .NET 中不安全或存在版本/授权风险。新系统应使用 JSON、明确的数据模型和受支持的 Excel 导出方案。

## 5. 推荐迁移顺序

1. 工作表多记录模型：记录 ID、说明、分类、创建时间、默认有效标记、历史版本。
2. 电阻试验完整命名字段：绝缘、18 路检温计、环境温湿度和仪表信息。
3. 空载试验计算与输入校验，建立第一套旧/新结果回归数据。
4. A 法效率分析，再依次迁移 B/C/E/H。
5. 报表导出与打印。
6. 设备抽象层和模拟器。
7. 在真实硬件上逐个接入 PLC、WT3K/WT1800、MW100/TP700、转矩和电阻仪。
