# 三相异步电机试验平台 Web 概念原型

这是一个独立的浏览器端交互原型，用于评审电机试验分析软件的网页端工作台。它复用遗留系统的项目、设备、实时字段、试验、记录版本、A/B/C/E/H 分析和报告流程语义，但不连接真实设备或数据库。

## 启动

```powershell
npm install
npm run typecheck
npm run test -- --run
npm run build
npm run dev -- --host 127.0.0.1
```

启动后访问 Vite 输出的本地 URL。HashRouter 默认进入 `/#/monitor`。

## 工作区

- `/#/project`：查看当前项目完整铭牌参数、项目级试验进度和项目列表；可从只读型号库预填并创建项目。
- `/#/monitor`：选择当前试验，查看实时测量、趋势、80 帧统计、告警、设备状态与记录点。
- `/#/tests`：按原始目录层级执行 21 个试验或分析项目，目录本身不可选择。
- `/#/records`：管理当前试验的记录版本、历史对比与 A/B/C/E/H 原型分析。
- `/#/reports`：按当前项目编号选择报告章节并导出 HTML 原型。
- `/#/settings`：管理 PLC、WT3K/WT3000、TP700、MW100、转矩转速通道与模拟配置。

## 项目与进度

“新建项目”表单包含项目/试验编号、样品名称、电机编号、型号、生产厂家、出厂编号、额定电压、电流、功率、频率、转速、功率因数、电机极数、接线方式、绝缘等级和操作员。选择型号库条目会复制一份可编辑快照，创建操作不会修改型号库或其他项目。

共享试验树固定包含 5 个目录和 21 个可执行叶子。项目概览、试验执行和实时监控使用同一棵树及同一份项目级进度。初始示例项目为 `3 / 21 已完成`，负载特性试验进行中；新建项目从 `0 / 21` 开始。采集运行、暂停或急停时，项目和试验上下文会锁定。

## 实时监控

主测量区按业务分为 17 项：

- 电气测量：三相线电压、三相电流和频率，共 7 项。
- 机械测量：转速和扭矩，共 2 项。
- 定子温度：U/V/W 三相绕组，共 3 项。
- 转子及部件温度：转子 U/V/W 三相绕组、DE1 轴承和铁芯，共 5 项。

统计栏显示平均电压、平均电流、有功功率、无功功率、轴功率和功率因数。每项同时显示最新值和最近 80 帧有限采样的平均值，合法零值参与统计。

## 两套方案

通过顶部“界面方案”选择器切换，项目、试验进度和 Mock 采集会话不会重置：

1. 精密实验台：项目树、实时值、记录表和曲线同屏。
2. 暗场控制室：波形墙、统计/告警轨、固定命令台。

## 交互范围

- 500 ms Mock 采集仿真，支持开始、暂停、继续、停止和记录当前点。
- 通道开关、趋势图、统计值、告警确认和逐设备连接/断开。
- 项目创建与切换、试验项目切换、历史记录对比、记录版本默认项切换。
- A/B/C/E/H 原型分析、报告章节选择、动态项目/试验命名的 CSV 与 HTML 下载。
- 停止、删除记录、断开设备、扭矩清零和覆盖默认分析结果均需确认。

## 目录

```text
src/
  App.tsx                 单一工作台、六工作区、项目表单和两套方案组合
  core/data.ts            中文业务 fixtures、设备、通道、试验原树和报告模板
  core/testItems.ts       21 个可执行叶子、目录状态和项目进度 helper
  core/metrics.ts         17 项测量配置、6 项统计配置和 80 帧平均

  core/Chart.tsx          ECharts 生命周期封装

```

## 验证

运行 `npm run typecheck`、`npm run test -- --run` 和 `npm run build`。浏览器检查以 1440x900、1024x768、390x844 为目标视口，覆盖方案 01/02 和六个工作区。

## 状态边界

本项目使用 Zustand 内存状态。刷新浏览器后，新建项目、项目进度变更和当前采集段都会回到 Mock 初始状态；本原型不提供持久化。

真实 PLC/WT3K/TP700/MW100 通信、Access 数据库、FlexCell/Aspose 模板、正式 A/B/C/E/H 公式、电子签章和生产权限系统均不在交付范围内。
